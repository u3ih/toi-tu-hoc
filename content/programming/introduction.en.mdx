I have only just started writing this section.

The way I learned to program looks a lot like the way I learned English: I got almost everything
wrong for the first two years, and only then found what worked for me. So I want to write it down,
the same way I did for the English section.

<Callout type="story">
In my first year I watched a lot of tutorials. I typed along line by line, it ran, and I felt like I
understood the material.

Then one day I opened an empty file and tried to write something tiny on my own. I stared at a blank
screen for fifteen minutes and couldn't type a single line.

That was when it clicked: watching someone else do it is not the same as being able to do it.
</Callout>

## What goes in here

Still personal notes, not a curriculum:

- The places I stayed stuck the longest, and what finally got me out.
- The order I wish someone had given me earlier.
- The tools I actually use, not a list padded out for length.

There aren't many articles here yet. I add to it when I have the time.
</Callout>
